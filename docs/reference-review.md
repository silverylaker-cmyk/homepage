## 제공 자료에서 수정할 부분

- 시안의 ‘진료 중’은 고정 문구다. 실제 일정·예외일을 반영하는 계산이 필요하다.
- 시안에는 존재가 확인되지 않은 학력·수면 인증·CT·VNG·소아 공간·무료 주차 정보가 있다. 실제 정보 확인 대상이다.
- 시안의 ‘자가체크 결과 문자 수신’은 동작 구현이 없다. 별도 제품·운영 범위로 정해야 한다.
- 모바일 메뉴는 숨겨지기만 하므로 실제 탐색 UI를 구현해야 한다.
- 기획자용 주석·설명 문구가 화면 본문에 포함되어 있다. 홈페이지 원고로 사용하지 않는다.
- HIRA 예제에는 검색 입력·앵커 등 미완성 예시와 오래된 마크업이 있다. 항목 구조를 활용해 재구현한다.
- 의료광고 관련 단정적 표현, 가격·요금·지도 API·서비스 기능은 현재 사실로 일괄 채택하지 않는다.

## 이번에 외부 확인한 자료

- [Next.js 정적 export](https://nextjs.org/docs/app/guides/static-exports): 정적 출력 설계 근거.
- [Servier](https://smart.servier.com/): CC BY 4.0 및 출처 표기 안내.
- [의료법 제56조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028699907): 원본의 일괄 금지 문구를 그대로 규칙화하지 않는 근거.
- [HIRA 공식 서식 안내 PDF](https://www.hira.or.kr/cms/diag/01/npayform_02.pdf): 공식 검색 결과에서 10종 서식 안내 확인. 원본 가이드의 HIRA 페이지 직접 열람은 실패하여 로컬 ZIP 내부를 확인했다.

벤치마킹 사이트 14곳을 이번에 모두 재방문한 것은 아니다. 해당 평가와 수치는 제공 문서의 조사 결과로 구분한다. PDF는 텍스트를 확인했으며 시각적 레이아웃 검수는 하지 않았다. PPTX도 구조·텍스트·포함 파일을 확인했으며 실제 도판 선정은 구현 단계에서 진행한다.

원본 대용량 파일은 이 레포에 복제하지 않았다. 다른 환경에서 구현할 경우 원본 폴더 또는 필요한 개별 소재를 전달한다.

## 사용자 답변에 따른 우선순위 변경

사용자는 알지 이비인후과·신매역, 만성/알레르기 비염·난청/이명·두경부 종양, 네이버 예약을 지정했다. 기존 자료의 수면·소아 중심 구성과 네이비·청록은 최신 계획에서 대체했다.

추가 디자인 참고: [Anthropic 홈페이지](https://www.anthropic.com/). 이번에는 웹 문서 구조를 확인했으며 렌더링 화면·CSS 측정은 수행하지 않았다. 계획의 색상·서체·레이아웃 수치는 이 프로젝트를 위한 제안이다. 구현 담당은 실제 시안을 확인하면서 사용자 취향에 맞춰 조정한다.

최신 보완: 환자 대상 대표 명칭을 **암**으로 수정하고 두경부 종양은 설명에 병기한다. 인체 클릭 시스템은 초기 필수 기능이다. 세부 동작은 `interaction-and-screen-spec.md`에 정의한다.
